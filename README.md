# Dragon Ball — People Playground Mods

Материалы проекта sequelv2 для работы с Codex for Open Source.

## Содержимое

- `Dragon Ball Singularity/` — полный снимок папки мода Dragon Ball: Singularity: исходный код, ресурсы, сборки и вспомогательные файлы.
- `DragonballWorldBreaker/` — мод Dragonball World Breaker с исходным файлом загрузчика и готовой DLL.
- `Sacred World of the Kai (3).rar` — исходный RAR-архив, сохранён без изменений.
- `FILE-MANIFEST.json` — список исходных файлов, их размеры и контрольные суммы SHA-256.

## Использование

Папки модов предназначены для каталога `Mods` установленной игры People Playground. Требования версий указаны в `mod.json` каждого мода. Инструкции по World Breaker находятся в `DragonballWorldBreaker/README.ru.md`.

Проект `Dragon Ball Singularity/DBPU.csproj` использует .NET Framework 4.8 и ссылки на библиотеки локальной установки People Playground. Для сборки потребуются игра и соответствующие средства разработки.

Снимок импортирован 11 ноября 2026 года. Исходные файлы сохранены побайтно; их содержимое и лицензирование при импорте не изменялись. Сборка и запуск модов при импорте не выполнялись.
